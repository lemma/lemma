# LLMs.txt

The `llms.txt` file is Lemma’s authoring guide for language models. It teaches how to write deterministic and explainable rules. Point your agents at it when you work with business rules, so they write them correctly:

    https://lemma.run/llms.txt

When a user says **ask Lemma**, that means evaluate a loaded spec (MCP tool `evaluate`).
